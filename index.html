e-nose: เครื่องดมความสุกและการเน่าของผลไม้

รวมทุกหน้าของโปรเจกต์ไว้ที่เดียว ตั้งแต่ตัวเครื่อง ผังต่อสาย แบบจำลองแก๊สในเครื่อง จนถึงเครื่องแนวคิด 2 แบบ: DS-300 สำหรับคัดในโรงคัด และ E-100 สำหรับให้ลูกค้าดมเช็กที่หน้าร้าน

ใหม่ Simulation: ตัวเครื่อง ภายใน และแก๊สที่จะวัด

ภาพตัด 3 มิติ เห็นห้องดม ห้องเซนเซอร์ TGS2602 / TGS2603 / BME688 ปั๊ม วาล์ว และ ESP32-S3 ปรับผลไม้ สด → สุก → เริ่มเน่า → เน่า แล้วดูอนุภาคแก๊สและกราฟเซนเซอร์เปลี่ยนตาม

ค่าทั้งหมดเป็นการจำลอง ไม่ใช่ข้อมูลวัดจริง

hamsterhub-projectโมเดล 3D เครื่องดมทุเรียน

หมุนดูชิ้นส่วน สลับเส้นทางลมรอบดม / รอบล้าง แตะเพื่อดูหน้าที่ของแต่ละชิ้น

 e-nose-wiring-diagramผังต่อสาย prototype

ESP32-S3 + ADS1115 + TGS2602 / TGS2603 + BME688 × 2 + ปั๊มและวาล์ว พร้อมตารางต่อขาและเช็กลิสต์ก่อนเสียบไฟ

 ds-300-graderDS-300 เครื่องคัดแบบพกพา

เครื่องตรวจแบบพกพาสำหรับสายคัดบรรจุ ทุเรียนต่อคิวเข้าห้องดมทีละลูก รอบวัดเส้นฐาน → สะสมกลิ่น → ดม → ล้าง อนุภาคแก๊ส กราฟ Rs/R0 และผลคัดเกรด (ค่าจำลอง)

 e-100E-100 เครื่องดมหน้าร้าน

เครื่องเล็กวางบนเคาน์เตอร์ ให้ลูกค้าดมเช็กทุเรียนพรีเมียมทีละลูกก่อนซื้อ เห็นไฟเกรดและผลเอง (แนวคิด ยังไม่ได้สร้างจริง)

 durian-ripening-roomห้องบ่มทุเรียน + เครื่องตรวจ

ห้องบ่ม 3D ทุเรียน 2 ชั้นบนพาเลท เครื่องตรวจติดผนังวัดเอทิลีน CO₂ อุณหภูมิ ความชื้น เร่งเวลาดูความสุกและพัดลมระบายอากาศอัตโนมัติ (แนวคิด ค่าจำลอง ไม่มีข้อมูลวัดจริง)

 docsเอกสารและสไลด์

สไลด์นำเสนอ v6 รายงานสารที่ผลไม้ปล่อยเมื่อเน่า และคลิปนำเสนอ ดูในเว็บหรือดาวน์โหลดได้

เครื่องทำงานอย่างไร

ไส้กรองคาร์บอน→วาล์ว 3 ทาง→ห้องดม (เฉพาะรอบดม)→ห้องเซนเซอร์→ปั๊มลม→ปล่อยทิ้ง

ESP32-S3 อ่านค่าเซนเซอร์ผ่าน I²C และ ADS1115 คิดเป็น Rs/R0 ของเซนเซอร์แต่ละตัว รวมเป็น "ลายนิ้วมือกลิ่น" แล้วเทียบกับค่าอ้างอิงจากการสอบเทียบเพื่อให้เกรดความสุก (เป็นแผน ทีมยังไม่มีข้อมูลวัดจริง จึงยังไม่มีเกณฑ์จริงและไม่อ้างความแม่นยำ) แล้วส่งผลผ่าน MQTT ขึ้นแดชบอร์ด (NETPIE / Node-RED) และแจ้งเตือนผ่าน LINE Messaging API

หน้าย่อย 2 หน้ามาจาก repo เดิม (hamsterhub-project, e-nose-wiring-diagram) เพิ่มแถบเมนู บรรทัดลิขสิทธิ์ และแก้ข้อความวิธีตัดสินผลให้ตรงกับแผนปัจจุบัน · ข้อมูลแก๊สในหน้า Simulation อ้างอิงไฟล์งานวิจัยของทีม (2026-10-26)
