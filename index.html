จมูกแมลงหวี่: เครื่องดมความสุกและการเน่าของผลไม้

รวมทุกหน้าของโปรเจกต์ไว้ที่เดียว ตั้งแต่ตัวเครื่อง ผังต่อสาย แบบจำลองแก๊สในเครื่อง จนถึงสมองแมลงหวี่ที่ใช้แยกกลิ่นด้วย FlyHash

ใหม่ Simulation: ตัวเครื่อง ภายใน และแก๊สที่จะวัด

ภาพตัด 3 มิติ เห็นห้องดม ห้องเซนเซอร์ TGS2602 / TGS2603 / BME688 ปั๊ม วาล์ว และ ESP32-S3 ปรับผลไม้ สด → สุก → เริ่มเน่า → เน่า แล้วดูอนุภาคแก๊สและกราฟเซนเซอร์เปลี่ยนตาม

เครื่องทำงานอย่างไร

ไส้กรองคาร์บอน→วาล์ว 3 ทาง→ห้องดม (เฉพาะรอบดม)→ห้องเซนเซอร์→ปั๊มลม→ปล่อยทิ้ง

ESP32-S3 อ่านค่าเซนเซอร์ผ่าน I²C และ ADS1115 รัน FlyHash เทียบคลังกลิ่น แล้วส่งผลผ่าน MQTT ขึ้นแดชบอร์ด (NETPIE / Node-RED) และแจ้งเตือนผ่าน LINE Messaging API
