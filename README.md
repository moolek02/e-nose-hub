# e-nose-hub

เว็บรวมของโปรเจกต์ e-nose ชุด A (ESP32-S3 + เซนเซอร์แก๊ส TGS2602 / TGS2603 / BME688) เปิดเป็น static site ได้ทันที ไม่ต้อง build

- `index.html` หน้ารวม
- `simulation.html` จำลองตัวเครื่อง ภายในเครื่อง และแก๊สที่จะวัด (**ค่าทั้งหมดเป็นการจำลอง ไม่ใช่ข้อมูลวัดจริง**)
- `ds-300-grader.html` DS-300 เครื่องคัดแบบพกพาสำหรับสายคัดบรรจุ ห้องดมตรวจทีละลูก + simulation แก๊ส (ค่าจำลอง)
- `e-100.html` E-100 เครื่องดมหน้าร้าน ให้ลูกค้าดมเช็กทุเรียนพรีเมียมก่อนซื้อ (แนวคิด ยังไม่ได้สร้างจริง ค่าจำลอง)
- `hamsterhub-project.html` โมเดล 3D (จาก repo hamsterhub-project)
- `e-nose-wiring-diagram.html` ผังต่อสาย (จาก repo e-nose-wiring-diagram)

หน้าที่คัดลอกมาเพิ่มแถบเมนู บรรทัดลิขสิทธิ์ และแก้ข้อความวิธีตัดสินผล (ลายนิ้วมือกลิ่นจาก Rs/R0 เทียบค่าอ้างอิงจากการสอบเทียบ เป็นแผน) ต้องต่ออินเทอร์เน็ตเพื่อโหลด Three.js และฟอนต์จาก CDN
